☁️ Cloud GitHub

❓ Première fois ? Le tuto complet (2 min)
  1. Crée un compte gratuit sur github.com si tu n'en as pas.
  2. Ouvre cette page : elle est déjà pré-réglée pour FGL.
  3. Dans Expiration, choisis « No expiration ». C'est important : avec une date, ta synchro s'arrêterait toute seule au bout de 30 jours sans prévenir.
  4. Vérifie qu'une seule case est cochée : « gist ». Jamais « repo ».
  5. Clique Generate token et copie le code ghp_…. GitHub ne l'affiche qu'une fois : garde-le dans tes notes.
  6. Colle-le ci-dessous puis Connecter. Sur ton téléphone : même site, même token, tout se retrouve.
• fgl-data.json — gist secret : toute ta collection, succès compris.
• fgl-profile.json — gist public : pseudo, avatar, bio, présence, top 10 et ta liste allégée. C'est celui-là que tes amis lisent.
Ne les supprime pas depuis GitHub, FGL les retrouve tout seul à chaque connexion.
