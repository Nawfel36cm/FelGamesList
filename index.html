☁️ Cloud GitHub

1. Ouvre cette page GitHub — la case gist est déjà cochée — puis « Generate token ».
2. Colle-le ici. Il reste sur cet appareil et n'est envoyé qu'à api.github.com.
3. Le même token sur ton PC et ton téléphone = la même liste partout.
• fgl-data.json — gist secret : toute ta collection, succès compris.
• fgl-profile.json — gist public : pseudo, avatar, bio, présence, top 10 et ta liste allégée. C'est celui-là que tes amis lisent.
Ne les supprime pas depuis GitHub, FGL les retrouve tout seul à chaque connexion.
